# Реестр потоков данных (AS-IS → TO-BE)

Документ детализирует стрелки на диаграммах [dfd-as-is.drawio](dfd-as-is.drawio) и
[dfd-to-be.drawio](dfd-to-be.drawio). Идентификаторы потоков (`Fx.y`) совпадают с подписями на диаграммах.

**Классы данных** (полное описание — в [Task3/README.md](../Task3/README.md)):

| Класс | Содержание |
|---|---|
| K1 | Специальная категория ПДн: сведения о состоянии здоровья, диагнозы, анализы, врачебная тайна |
| K2 | ПДн: ФИО, дата рождения, телефон, e-mail, адрес, паспорт, СНИЛС, ИНН |
| K3 | Финансовые и платёжные данные, банковская тайна |
| K4 | Коммерческая тайна: цены, условия поставщиков, себестоимость |
| K5 | Служебные данные: учётные записи, журналы, метаданные |
| K0 | Обезличенные и общедоступные данные |

**Меры защиты** (`Cn`) — каталог продублирован на каждой странице `dfd-to-be.drawio`:
C1 TLS 1.3/mTLS · C2 OIDC + MFA · C3 ABAC/RBAC через PDP · C4 токенизация в PII Vault ·
C5 шифрование at rest · C6 маскирование и обезличивание · C7 WORM-аудит и SIEM · C8 DLP ·
C9 Consent и Retention · C10 Data Catalog и Lineage · C11 contract-first API · C12 сегментация сети.

## Сводка по каналам передачи

| Канал AS-IS | Кол-во потоков | Основная угроза | Целевое состояние |
|---|---|---|---|
| SMB к общему диску | 14 | Чтение и копирование данных любым сотрудником | API + PDP, доступ к файлам только через Document Service |
| Excel как хранилище | 9 | Отсутствие разграничения, дубли, отсутствие аудита | PostgreSQL с RLS и шифрованием полей |
| E-mail (Exchange, личная почта) | 6 | Передача без шифрования, бессрочные копии во вложениях | Уведомления и callback через сервисы, DLP на исходящие |
| Бумага | 7 | Данные вне периметра и вне учёта | Электронные формы и согласия |
| OLE / TCP-IP между 1С и ККМ | 3 | Нет аутентификации и журналирования | Интеграционная шина и защищённый шлюз ККМ |
| USB и личные устройства | 3 | Неконтролируемый вынос данных | Запрет политиками + DLP |
